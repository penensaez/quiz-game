# SP Trivia Quiz 🧠

A web-based trivia quiz app built with Python and Streamlit. Answer 5 multiple-choice questions and see how you score!

## Features

- 5 multiple-choice trivia questions across geography, science, math, and coding
- Score tracking with a final percentage result
- Play again without restarting the app

## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/penensaez/quiz-app.git
cd quiz-app
pip install streamlit
```

### Run

```bash
streamlit run quiz_app.py
```

Then open your browser to `http://localhost:8501`.

## How to Play

1. Read each question and select your answer
2. Click **Submit** to move to the next question
3. After all 5 questions, see your final score and percentage
4. Hit **Play Again** to restart
